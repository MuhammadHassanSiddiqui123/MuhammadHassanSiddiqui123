### 🔭 Featured Project

**[Pearls AQI Predictor](https://github.com/MuhammadHassanSiddiqui123/aqi-predictor)** — a fully serverless system forecasting Karachi's Air Quality Index 3 days ahead. Hourly ingestion, daily retraining across 5 model architectures, SHAP explainability, and a live public dashboard — all running unattended on free-tier infrastructure.

- 🏆 Champion model: Ridge Regression, R² = 0.866 (1-day forecast)
